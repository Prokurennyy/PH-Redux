# PH Redux

Установка редуксов и сетов для GTA 5 (Steam / Epic) — с очередью и откатом. От автора [PsychoHUB](https://github.com/Prokurennyy/PsychoHUB).

## ⬇ Скачать

**[Последняя версия → PH-Redux.exe](https://github.com/Prokurennyy/PH-Redux/releases/latest)**

Один портативный файл: устанавливать ничего не нужно. Требуется Windows 10/11 (64-бит) и права администратора — без них нельзя писать в папку игры.

> При первом запуске Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее → Выполнить в любом случае».

## Как пользоваться

1. Программа сама находит GTA 5. Если нет — «Обзор…» и папка, где лежит GTA5.exe.
2. Перетащи файлы: архивы редуксов, .oiv, settings.xml. Можно сразу пачкой и в любой момент.
3. Проверь порядок в очереди (▲ ▼) и нажми «Установить всё по очереди».
4. На каждом .oiv откроется OpenIV — установи пакет там и нажми «Готово, дальше».

Откатить любую установку — в списке «Установленные редуксы и сеты» внизу. Откат идёт по порядку: чтобы вернуть старую установку, сначала откатываются более новые.

## Что важно знать

- Rockstar Launcher проверяет файлы и возвращает оригиналы — редукс на нём не удержится. Поддерживаются Steam и Epic.
- Бэкапы лежат в `C:\ProgramData\PsychoHUB\redux\`.
- Закрой GTA 5 и OpenIV перед установкой — программа напомнит.
